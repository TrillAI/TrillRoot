# Changelog

## 0.2.0 — 2026-11-03

- Renamed the displayed product to **Trill Root**.
- Added AMOLED-black styling and bright multicolor neon headings.
- Added first-run branded fade screens, full scroll-gated Terms of Use, permission disclosure, and ten-step transparent identification progress.
- Added a conservative, explainable auto-detected root-readiness verdict.
- Explicitly documents why historical one-click exploit families are not safe unknown-device fallbacks.


## 0.1.0 — 2026-11-03

Initial native Android preview.

- Offline device and boot-signal snapshot.
- Explicit, read-only existing-root check with timeout and bounded output.
- Magisk, Samsung, KernelSU, and legacy-recovery guidance.
- Local preparation checklist and user-directed report export.
- API 23 minimum, API 36 target, no declared permissions.
- Direct SDK build, Gradle project, JVM regression suite, and CI build workflow.

This release is a root-readiness assistant, not a root installer or exploit tool.
